# Supabase 연동 검증 체크리스트

SQL 실행 후 앱이 DB와 잘 연동되는지 확인하는 방법입니다.

---

## 1. 환경 변수 확인

앱 루트(`mebody/`)에 `.env` 파일이 있고, 아래 두 값이 **실제 프로젝트 값**으로 들어가 있어야 합니다.

- `VITE_SUPABASE_URL` — Supabase 프로젝트 URL (예: `https://xxxx.supabase.co`)
- `VITE_SUPABASE_ANON_KEY` — Supabase **anon public** 키 (Project Settings → API)

비어 있거나 잘못되면 API 호출이 실패하고, 결과/가이드는 폴백(로컬 데이터)으로만 동작합니다.

---

## 2. 앱 빌드 확인

터미널에서:

```bash
cd mebody
npm run build
```

에러 없이 `built in ...` 나오면 OK.

---

## 3. 화면 플로우로 확인 (수동)

1. `npm run dev` 로 실행 후 브라우저에서 접속
2. **시작 → 동의 → 진단 시작 → 문항 답변** 후 결과 화면까지 진행
3. **결과 화면**에서 확인:
   - 상단에 **나의 mebody 코드** (FRRS 등) 표시
   - **0)~5) 아코디언** 클릭 시 내용 펼쳐짐  
     - DB에 FRRS 데이터를 넣었다면: 0)~5)에 워드/DB 내용 표시  
     - 넣지 않았다면: 0) 설명, 1) 축 요약, 5) 운동·팁 등 **폴백** 표시
4. **다음 페이지** 클릭 → **자세 사용 설명서** 화면
   - **공통** 4개 섹션(핵심 원칙, 50% Rule, 4가지 습관, 오늘의 목표) 표시되면 `result_guide`(공통) 연동 OK
5. 다시 **다음 페이지** → **맞춤 가이드** 화면
   - FRRS 등 체형별 가이드를 넣었다면 해당 섹션 표시
   - **내 mebody 코드 더 알아보기** 버튼 클릭 → 심화 안내(플레이스홀더) 화면으로 이동하면 OK

---

## 4. Network로 API 호출 확인 (선택)

1. **F12** → **Network** 탭 연 다음, 결과 화면으로 이동(또는 새로고침)
2. 필터에 `supabase` 또는 `rest/v1` 입력
3. `result_guide`, `body_code_result_sections`, `app_images` 등으로 요청이 가고, **Status 200**이면 연동 정상

**빠른 확인**: 결과 화면에서 **0) 내 체형 코드 알아보기**를 펼쳤을 때  
- DB에 넣은 문구가 보이면 → `body_code_result_sections` 연동 OK  
- "당신의 체형 코드는 **FRRS**입니다..." 같은 기본 문구만 보이면 → 폴백(DB 미연동 또는 해당 코드 데이터 없음)

---

## 5. 정리

| 확인 항목 | 확인 방법 |
|-----------|-----------|
| 빌드 성공 | `npm run build` 에러 없음 |
| 환경 변수 | `.env`에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` 설정 |
| 결과 0~5 아코디언 | 결과 화면에서 0)~5) 펼쳐서 내용 표시 (DB 또는 폴백) |
| 자세 사용 설명서 | 다음 페이지 → 공통 4개 섹션 표시 |
| 맞춤 가이드 / 더 알아보기 | 다음 페이지 한 번 더 → 체형별 섹션·버튼 동작 |

문제가 있으면 브라우저 **F12 → Console**에서 빨간색 에러 메시지와 **Network** 탭에서 실패한 요청(빨간 줄)을 확인하면 됩니다.
