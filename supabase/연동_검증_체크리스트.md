# Supabase 연동 검증 체크리스트

## 1. 환경변수
`.env` 또는 Vercel 환경변수에 아래 값이 있어야 합니다.

```env
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
```

## 2. SQL 데이터 확인
Supabase SQL Editor에서 실행합니다.

```sql
SELECT
  (SELECT count(*) FROM public.questions WHERE is_active = true) AS questions_count,
  (SELECT count(*) FROM public.questions WHERE is_precheck = true AND is_active = true) AS precheck_count,
  (SELECT count(*) FROM public.questions WHERE is_scored = true AND is_active = true) AS scored_count;
```

기대값:
- `questions_count = 53`
- `precheck_count = 4`
- `scored_count = 49`

Ver6 액션 확인:
```sql
SELECT
  (SELECT count(*) FROM public.immediate_action_discomfort_mapping WHERE is_active = true) AS discomfort_mapping_count,
  (SELECT count(*) FROM public.immediate_action_axis_mapping WHERE is_active = true) AS axis_mapping_count,
  (SELECT count(*) FROM public.immediate_action_content) AS action_content_count;
```

## 3. 로컬 빌드
```bash
npm run build
```

에러 없이 끝나면 기본 타입/번들 검증은 통과입니다.

## 4. 브라우저 플로우
확인할 항목:
- 비회원 새 접속은 랜딩으로 시작합니다.
- 53문항 건너뛰기 후 결과 페이지로 이동합니다.
- 결과 페이지에서 임시 코드 플랜 진입 시 최신 액션 UI가 보입니다.
- 1순위 액션과 2순위 액션 카드가 분리되어 보입니다.
- 0% 미션 영역을 누르면 1순위 액션이 열립니다.
- 50% 상태에서는 남은 액션이 열립니다.
- 100% 상태에서는 어느 영역을 눌러도 전체 액션 보기가 열립니다.
- 액션 상세에 관리 부위, 타겟 근육, 이완 방법, 스트레칭 방법, 시간/세트, 주의사항이 표시됩니다.

## 5. 이미지 확인
Storage bucket `images` 안에 아래 경로가 있어야 합니다.
- `characters/{BODY_CODE}.png`
- `axis/axis-neck.png`
- `axis/axis-shoulder.png`
- `axis/axis-pelvis.png`
- `axis/axis-flexibility.png`
- `body-types/bodyTypesImage.png`

브라우저 Network에서 Storage URL이 200으로 내려오면 정상입니다.

## 6. 로그인 사용자 확인
- 로그인하면 랜딩에서 최근 결과 바로 보기가 노출됩니다.
- 최근 결과 바로 보기를 누르면 코드 플랜 풀스크린 모달이 열립니다.
- 로그아웃하면 결과 상태와 URL 파라미터가 정리되고 랜딩으로 돌아갑니다.
