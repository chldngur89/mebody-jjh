# Supabase Storage 이미지 업로드 안내

## Bucket
- 이름: `images`
- 권한: Public

## 업로드 경로
```text
images/
  axis/
    axis-neck.png
    axis-shoulder.png
    axis-pelvis.png
    axis-flexibility.png
  body-types/
    bodyTypesImage.png
  characters/
    FRRS.png
    FRRF.png

    FRLF.png
    FLRS.png

    CRRS.png

    CRLS.png
    CRLF.png
    CLRS.png

    CLLS.png
    CLLF.png
```

## 공개 URL 형식
프로젝트 URL이 `https://xxxx.supabase.co`라면 형식은 아래와 같습니다.

```text
https://xxxx.supabase.co/storage/v1/object/public/images/characters/FRRS.png
https://xxxx.supabase.co/storage/v1/object/public/images/axis/axis-neck.png
https://xxxx.supabase.co/storage/v1/object/public/images/body-types/bodyTypesImage.png
```

## 앱 로딩 우선순위
캐릭터 이미지:
1. Storage `characters/{BODY_CODE}.png`
2. `app_images`의 `character_{BODY_CODE}` URL
3. 로컬 fallback

축 아이콘:
1. Storage `axis/*.png`
2. `app_images` URL
3. 로컬 fallback

16가지 체형 이미지:
1. Storage `body-types/bodyTypesImage.png`
2. `app_images.body_types_image`
3. 로컬 fallback

## 점검 방법
- Supabase Storage에서 파일을 클릭해 공개 URL을 열어봅니다.
- 브라우저에서 이미지가 직접 열리면 권한과 경로는 정상입니다.
- 앱에서 깨지면 파일명 대소문자와 경로를 먼저 확인합니다.
