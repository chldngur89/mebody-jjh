## 2. Supabase Storage 준비 (한 번만)

1. **Supabase 대시보드** → 왼쪽 메뉴 **Storage** 클릭.
2. **New bucket** 클릭.
3. 이름 예: `images` (또는 `mebody-images`).
4. **Public bucket** 을 켜서 공개 URL로 접근 가능하게 합니다.
5. **Create bucket** 으로 생성.

(이미 만든 버킷이 있으면 그걸 사용해도 됩니다.)

---

## 3. 폴더 구조와 업로드

버킷 안에 아래처럼 폴더를 나누면 관리하기 쉽습니다.

```
images/                    ← 버킷 이름이 images 인 경우
├── axis/                  ← 축 아이콘 (선택)
│   ├── axis-neck.png
│   ├── axis-shoulder.png
│   ├── axis-pelvis.png
│   └── axis-flexibility.png
├── body-types/            ← 16가지 체형 이미지 (선택)
│   └── bodyTypesImage.png
└── characters/            ← 체형별 캐릭터 (선택)
    ├── FRRS.png
    ├── FRRF.png
    ├── ... (나머지 14개)
    └── CLLF.png
```

**업로드 방법**

1. Storage에서 해당 버킷 선택.
2. **New folder** 로 `axis`, `body-types`, `characters` 생성.
3. 각 폴더 들어간 뒤 **Upload file** 로 위 표의 파일들을 올립니다.

## 4. 공개 URL 확인 및 app_images 에 반영

업로드한 파일을 클릭하면 오른쪽에 **URL**이 나옵니다.

형식 예:

- `https://[프로젝트ID].supabase.co/storage/v1/object/public/images/axis/axis-neck.png`
- `https://[프로젝트ID].supabase.co/storage/v1/object/public/images/characters/FRRS.png`

이 URL을 **Supabase Table Editor** 의 `app_images` 테이블에서 해당 `key` 행의 `url` 컬럼에 넣으면 됩니다.

| key | url (예시) |
|-----|-------------|
| axis_neck | `https://xxxxx.supabase.co/storage/v1/object/public/images/axis/axis-neck.png` |
| character_FRRS | `https://xxxxx.supabase.co/storage/v1/object/public/images/characters/FRRS.png` |
| body_types_image | `https://xxxxx.supabase.co/storage/v1/object/public/images/body-types/bodyTypesImage.png` |

- Table Editor → **app_images** → 해당 행 선택 → `url` 필드에 위처럼 붙여넣기 → 저장.

한 번에 여러 행을 바꾸고 싶다면 **SQL Editor**에서 아래처럼 실행해도 됩니다 (실제 URL로 바꿔서 사용).

```sql
-- 예: 버킷 이름이 images, 폴더 구조가 위와 같을 때 (실제 프로젝트 URL로 수정)
UPDATE app_images SET url = 'https://[프로젝트ID].supabase.co/storage/v1/object/public/images/axis/axis-neck.png' WHERE key = 'axis_neck';
UPDATE app_images SET url = 'https://[프로젝트ID].supabase.co/storage/v1/object/public/images/axis/axis-shoulder.png' WHERE key = 'axis_shoulder';
UPDATE app_images SET url = 'https://[프로젝트ID].supabase.co/storage/v1/object/public/images/axis/axis-pelvis.png' WHERE key = 'axis_pelvis';
UPDATE app_images SET url = 'https://[프로젝트ID].supabase.co/storage/v1/object/public/images/axis/axis-flexibility.png' WHERE key = 'axis_flexibility';
UPDATE app_images SET url = 'https://[프로젝트ID].supabase.co/storage/v1/object/public/images/body-types/bodyTypesImage.png' WHERE key = 'body_types_image';
UPDATE app_images SET url = 'https://[프로젝트ID].supabase.co/storage/v1/object/public/images/characters/FRRS.png' WHERE key = 'character_FRRS';
-- ... character_FRRF, FRLS, ... CLLF 도 같은 방식으로
```

## 5. 요약

| 구분 | 개수 | 필수 여부 | 비고 |
|------|------|-----------|------|

- 이미지 없이도 앱은 동작하며, 올린 이미지부터 Storage URL로 표시됩니다.
