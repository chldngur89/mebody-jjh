# Screen Spec 07 (코드 출력 및 결과페이지 무료 제공 화면-2) 검증

스펙 이미지 기준으로 현재 구현이 어떻게 맞는지 정리한 문서입니다.

---

## 스펙 요약

- **레이아웃**: "나의 mebody 코드" 카드 형태, **아코디언(접기/펼치기)** 구조.
- **섹션 구성** (클릭 시 펼쳐지게, **내용은 워드 파일로 첨부**):
  - **0)** 내 체형 코드(FRRS)에 대해서 알아보기 ↓
  - **1)** 한눈에 보는 내 코드 ↓ (목 F, 어깨 R, 골반 R, 하체 S 등)
  - **2)** 이해 포인트 ↓ (움직임 패턴)
  - **3)** 공감 포인트 ↓ (공통 감각/습관)
  - **4)** 지금 주의하면 좋은 자세 ↓
  - **5)** 무료 10~15분 자가 루틴 ↓
- **버튼**: 하단에 **"다음 페이지 >"** → 다음 카드 블록으로 이동.
- **3번째 블록**: 4) 심화 버전 태그 미리보기 + **"내 mebody 코드 더 알아보기"** (녹색 CTA).  
  현재는 **잠금 없이 클릭 시 심화 페이지로 이동**하도록 설정.

## 결론

- **스펙처럼 되어 있지 않은 부분**
  - 결과 페이지가 **0)~5) 아코디언**이 아니라 **한 페이지 풀 스크롤**.
  - 결과 하단 버튼이 **"다음 페이지 >"**가 아니라 **"프로그램 시작"**.
  - **"내 체형 코드 알아보기 / 한눈에 보는 내 코드 / 이해 포인트 / 공감 포인트 / 주의 자세 / 무료 자가 루틴"** 같은 **스펙 번호·제목 구조**가 결과/다음 화면에 없음.
  - **"내 mebody 코드 더 알아보기"** 심화 CTA 없음.

- **스펙과 비슷하게 되어 있는 부분**
  - **아코디언**은 **자세 사용 설명서 화면(ResultGuideScreen)**에 적용됨 (공통 워드 내용).
  - **"다음 페이지 >"**로 다음 화면(NextPageScreen)으로 넘어가는 플로우는 있음 (단, 결과 화면이 아닌 자세 사용 설명서 화면에서).
  - 카드형·둥근 모서리·버튼 스타일 등 **비주얼 톤**은 비슷함.

- **스펙 07과 완전히 같은 처리가 나오도록 하려면**
  - 결과 화면을 **0)~5) 아코디언** 구조로 재구성하고,
  - 체형별 워드 내용을 **0)~5)용**으로 DB/데이터에 넣은 뒤,
  - 결과 하단 버튼을 **"다음 페이지 >"**로 바꾸고,
  - **"내 mebody 코드 더 알아보기"** 버튼을 추가해 (현재는 잠금 없이) 심화 페이지로 이동시키는 작업이 필요합니다.
