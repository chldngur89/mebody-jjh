# MEBODY 테스터 체험기 — 2026-10-06

신규 사용자인 척 앱을 처음부터 끝까지 써 보고 걸린 것들을 적었습니다.
기기: Android 에뮬레이터(API 36) · 디버그 빌드 · 데이터 초기화 후 첫 실행.

**읽는 법**: 전부 실제로 재현한 것만 적었습니다. 추측은 "확인 못 함" 이라고 따로 적었습니다.

---

## 0. 제가 남긴 기록

운영 DB 와 기기에 이런 흔적이 남았습니다.

- **익명 진단 응답 1건** — 32문항을 끝까지 풀어 결과(F-R-R-S)가 만들어졌습니다. 로그인 전이라
  `questionnaire_responses` 에 익명으로 남아 있습니다.
- **장바구니 1건** — 「마사지볼 듀오」. 기기 안(sessionStorage)에만 있습니다.
- **테스트 광고 클릭 1회** — 문항을 끝낸 직후 자동 입력이 「다음」 자리를 눌렀는데 그 자리가
  결과 화면에서는 배너였습니다(아래 5번). 배너에 **Test Ad** 라벨이 있어 과금 영향은 없습니다.
- **계정은 만들지 않았습니다.** 운영 Supabase 에 비밀번호를 입력해 계정을 만드는 일이라
  제가 하지 않았습니다. 로그인이 필요한 화면(루틴·내 상태·바디 노트)은 못 봤습니다.

## 1. 출시를 막는 것

### 1-1. 출시해도 **테스트 광고만** 뜹니다 — 수익 0

`capacitor.config.ts` 에 이렇게 박혀 있고, 그대로 APK 안
(`android/app/src/main/assets/capacitor.config.json`)에 들어갑니다.

```
// 테스트 기기에서는 항상 테스트 광고를 띄웁니다. 실기기 실광고는 스토어 배포 후.
initializeForTesting: true,
```

코드(`src/lib/ads.ts`)는 `AdMob.initialize({ initializeForTesting: !hasRealAdUnits() })` 로
**false** 를 넘기지만, 플러그인 자체 설정이 따로 걸립니다. 실제로 지금 빌드에서 뜨는 배너에
**Test Ad** 라벨이 붙어 있습니다.

주석이 "실기기 실광고는 스토어 배포 후" 라고 적어 둔 그대로, **아직 안 바꿨습니다.**
이대로 올리면 광고는 나오는데 돈은 한 푼도 안 들어옵니다.

### 1-2. 오프라인에서 **"결과를 찾을 수 없습니다"** 라고 거짓말합니다

비행기모드로 앱을 열면 이렇게 나옵니다.

> **결과를 찾을 수 없습니다**
> 저장된 결과를 찾지 못했습니다. 홈에서 다시 분석하면 새 결과를 만들 수 있어요.
> [ mebody Code 다시 확인하기 ]

**결과는 멀쩡히 있습니다.** 네트워크를 되살리자 F-R-R-S 가 그대로 돌아왔습니다.
지하철에서 앱을 연 사람은 "내 결과가 날아갔구나" 로 읽고, 버튼이 시키는 대로
**32문항을 다시 풉니다.**

같은 상태에서 탭도 안 바뀝니다(마켓을 눌러도 홈에 그대로). 오프라인이라는 표시가
화면 어디에도 없습니다.

### 1-3. 장바구니 끝이 **「결제 준비 중」** 입니다

상품을 담고 수량까지 고를 수 있는데 마지막이 이렇습니다.

> ⓘ 결제 서버가 아직 연결되지 않았습니다.
> [ 결제 준비 중 ]  ← 눌리지 않음

담을 수 있으면 살 수 있다고 믿습니다. 결제를 붙이든지, 아니면 출시 때는 마켓을
"둘러보기" 로만 두고 담기를 감추는 쪽이 낫습니다.

## 2. 크게 거슬린 것

### 2-1. 회원가입 버튼을 눌러도 **아무 일도 안 일어납니다**

빈 양식에서 「회원가입하고 저장」을 눌렀습니다. 화면 변화 **0픽셀**. 오류도, 빨간 테두리도,
흔들림도 없습니다. 왜 안 되는지 알 길이 없습니다.

버튼 아래에 "위 두 가지에 동의하면 가입할 수 있습니다" 가 작게 있긴 한데, 버튼을 누른
사람은 버튼을 보고 있지 그 아래를 안 봅니다.

진단 동의 화면은 버튼 **글자 자체가** 「두 가지에 동의해 주세요」로 바뀌는데
가입 화면은 그렇지 않습니다. 같은 앱에서 방식이 다릅니다.

### 2-2. 문항 「다음」 자리에 결과 화면의 **광고**가 옵니다

- 문항 화면: 「다음」 버튼이 화면 아래 `y ≈ 2240`, 광고 없음
- 결과 화면: 같은 `y` 에 **AdMob 배너**

마지막 문항에서 「다음」을 누르면 결과 화면이 뜨는데, 로딩이 느려 한 번 더 누르면
그 손가락이 광고에 떨어집니다. 제가 그렇게 눌렀고 브라우저가 열렸습니다.

사고로 눌리는 광고는 구글이 싫어하는 바로 그 배치입니다.

### 2-3. 마켓에서 **장바구니로 가는 길이 맨 아래에만** 있습니다

상품 카드의 `+` 를 눌렀습니다. 확인 표시가 잠깐 뜨고 끝입니다.
위로 올려도 장바구니 아이콘이나 뱃지가 **없습니다.**

「장바구니 1개 보기」 버튼은 **상품 15개를 다 지나친 맨 아래**에 있습니다.
담은 걸 보려면 거기까지 스크롤해야 합니다.

## 3. 중간

### 3-1. 축 소개 슬라이더를 **입력인 줄 알고 만졌습니다**

문항 직전 화면입니다.

> 아래 4개 축을 기준으로 나의 mebody Code를 계산합니다
> 정답을 맞히는 방식이 아니라, **지금 몸이 더 가깝게 느끼는 방향을 선택해주면 됩니다.**
>
> 목 [━━●━━━] · 어깨 [━━━●━] · 골반 [━●━━━] · 하체 [━━●━━]

"선택해주면 됩니다" 바로 아래에 손잡이 달린 슬라이더가 **스스로 움직입니다.**
저는 당연히 끌어서 답하는 줄 알고 끌었습니다. 아무 반응이 없습니다.

알고 보니 이건 `AxisIntroDemo` 애니메이션이고(3초 두고 보면 혼자 움직입니다),
"선택해주면 됩니다" 는 **다음 화면의 32문항** 이야기였습니다.

### 3-2. 32문항이 **얼마나 걸리는지 아무도 안 알려줍니다**

랜딩에는 로고·한 줄·버튼뿐입니다. 몇 문항인지, 몇 분 걸리는지, 결과로 뭘 받는지가 없습니다.
자동 입력으로도 **약 2분**이 걸렸습니다. 사람이 사진 보고 읽으면서 하면 4~6분입니다.

시작 버튼 위아래로 빈 공간이 넓어서 "이게 다인가" 싶습니다.

### 3-3. 스크롤 화살표가 **담기 버튼을 덮습니다**

마켓 상품 격자에서 오른쪽 아래 떠 있는 `⌄` 버튼이 오른쪽 열 상품의 `+` 자리에 겹칩니다.

### 3-4. 마켓 「전체」가 **선택된 것처럼 안 보입니다**

제목은 「전체 상품 15개」인데 카테고리 타일 6개가 전부 흰색입니다.
처음 들어가면 「전체」가 초록인데, 스크롤을 오르내리면 선택 표시가 사라져 있습니다.

### 3-5. 장바구니에 **배송비 줄이 없습니다**

상품 금액 15,000원 → 최종 결제 15,000원. 배송비가 공짜인지, 나중에 붙는지 알 수 없습니다.

### 3-6. **이메일 확인 없이** 가입됩니다

가입 양식에 "확인 절차 없이 바로 가입됩니다" 라고 적혀 있습니다.
남의 이메일 주소로 가입할 수 있다는 뜻입니다. 몸 기록을 담을 앱이라 한 번 더 생각할 자리입니다.

### 3-7. 루틴·내 상태 탭이 **로그인 벽 하나**

미션 탭은 이번에 고쳐서 공통 스트레칭이 무엇인지 먼저 보여줍니다.
**루틴과 내 상태는 아직 버튼 하나뿐**입니다. 같은 손질이 필요합니다.

## 4. 확인 못 한 것

계정을 만들지 않아서 못 본 것들입니다. 테스터 계정을 하나 주시면 이어서 보겠습니다.

- 로그인 후 미션 수행 → 피드백 → 주사위 적립
- 14일 루틴 시작과 하루 흐름
- 내 상태의 적립금·기록
- **바디 노트** (074 는 적용됐지만 화면이 아직 없습니다 — STEP 3)
- 전문가 연결(VIP) 화면 — 전문가 계정도 필요합니다
- 비밀번호 재설정 메일 링크가 앱으로 돌아오는지

## 5. 제 판단 — 먼저 고칠 순서

| 순위 | 항목 | 이유 |
|---|---|---|
| 1 | `initializeForTesting: true` | 그대로 내면 광고 수익이 0입니다. 한 줄입니다 |

| 5 | 가입 버튼 무반응 | 가입 포기로 바로 이어집니다 |
| 6 | 마켓 장바구니 입구 | 담은 걸 못 찾습니다 |
| 7 | 나머지 (3장) | 출시를 막지는 않습니다 |
