# 모바일 웹 플로우 개선 적용 결과

검증일: 2026-09-05, 추가 검증: 2026-09-07
기준 보고서: [최초 문제 보고서](APP_FLOW_AUDIT_2026-09-05.md)

기존 작업을 보존한 상태에서 로컬 코드를 수정했다. 배포, 실결제, 운영 DB 변경은 하지 않았다. 아래의 적용 완료는 실제 회원 환경 전체 검증 완료를 뜻하지 않는다.

## 적용 내역

| 항목 | 개선 내용 | 검증 수준 |
| --- | --- | --- |
| F01 | 화면·탭·문항을 브라우저 이력과 동기화. 뒤로·앞으로 이동과 중복 뒤로 클릭 방지. 완료된 설문 이력을 정리해 재제출 경로 방지 | 브라우저 실행 + 자동 검사 |
| F02, F03 | 미응답 문항에서도 이전 버튼 표시. 이전 답변으로 돌아오면 다음 버튼 활성 상태 복원 | 브라우저 실행 |
| F04 | 설문 답변·현재 문항·초안 식별자를 상위 상태와 세션 저장소에 보관 | 로그인 취소·새로고침 실행 + 저장 형식 자동 검사 |
| F05–F08 | 로그인 취소, 재측정 취소, 멤버십 로그인 복귀, 장바구니 직접 진입 시 복귀 목적지 수정 | 비회원 브라우저 실행 |
| F09 | 탭별 스크롤 및 마켓 검색·카테고리 유지 | 스크롤 2007px 복원·검색 유지 실행 |
| F10 | 설문 임시 건너뛰기 제거, 미리보기 진입은 개발 환경으로 제한 | 코드 검토·프로덕션 빌드 |
| F11 | 제목·메타 설명 문항 수를 32로 수정 | 코드 검토·빌드 |
| F12 | 미션 정보가 없을 때 오늘 화면으로 돌아가는 버튼 제공 | 코드 검토·타입 검사 |
| F13 | 마켓 로딩 실패 안내와 재시도 버튼 추가 | 연결 실패 환경 브라우저 실행 |
| C01 | 지난 측정 결과의 선택 ID를 실제 결과 화면에 전달 | 코드 검토·경로 자동 검사; 회원 실데이터 미검증 |
| C02, C03 | 저니 뒤로가기 및 멤버십 복귀에 진입 경로 반영 | 코드 검토; 회원 진행 미검증 |
| C04 | 피드백 저장 실패 시 화면 유지·오류 표시, 중복 저장 방지. 성공한 경우만 완료 이동 | 코드 검토; 회원 API 실패 재현 미검증 |
| C05 | 루틴·미션 타이머 잔여 시간 저장, 재진입 시 일시정지 상태 복원 | 저장값 자동 검사; 회원 UI 미검증 |
| C06 | 분석 저장 15초 제한과 취소 처리. 화면 이탈 후 늦은 응답에 의한 이동 방지 | 제한시간·취소 자동 검사 및 비회원 결과 생성 실행 |

피드백 시트, 동작 상세 오버레이, 주소 입력창에는 브라우저 뒤로가기로 먼저 닫히도록 이력 처리를 추가했다. 회원 전용 시트의 전체 상호작용은 테스트 계정으로 추가 확인해야 한다.

## 실제 실행 확인

- 시작 화면 로그인 취소 → 시작 화면.
- 시작 → 동의에서 브라우저 뒤로/앞으로 → 시작/동의.
- 2번 문항에서 이전 → 1번 답변 및 다음 버튼 복원.
- 설문 도중 로그인 취소와 새로고침 → 현재 문항 유지.
- 비회원 32문항 순차 응답 → 분석 → 로컬 결과 표시.
- 마켓 검색 후 로그인 취소 → 검색어 유지. 탭 전환 후 스크롤 위치 복원.
- 장바구니 개발용 직접 진입 → 마켓으로 복귀.
- 멤버십 상단 로그인 취소 → 멤버십 복귀.
- 추가 확인: 개발 서버의 임시 테스트 픽스처로 31번 문항부터 결과를 생성한 뒤, 브라우저 뒤로 한 번 → 시작 화면, 앞으로 → 결과. 이 검사는 완료 이력 정리 검증이며 전체 32문항 재실행은 아니다.
- 결과 → 재측정 동의 → 화면의 뒤로 → 기존 결과 복원.

테스트 서버는 127.0.0.1:3108, API는 연결되지 않은 로컬 주소 127.0.0.1:3199로 설정했다. 개발용 테스트 진입 확장은 /tmp의 Vite 설정에만 있으며 앱 소스에는 추가하지 않았다. 앞선 모바일 웹 검사는 390×844 브라우저 화면으로 실행했고 실제 휴대폰 검증은 하지 않았다.

## 자동 검사

- `npm run typecheck`: 통과.
- `npm run verify:flow`: 29개 통과. 이력 검증, 설문 상태, 타이머 저장값, 요청 제한시간 및 취소 등.
- `npm run verify:journey-rules`: 112개 통과.
- `npm run build`: 통과.
- `git diff --check`: 통과.

자동 검사는 브라우저 전체 E2E를 대체하지 않는다. 빌드에는 journey 모듈의 정적/동적 import 혼용 경고가 남아 있으며, 검사 스크립트 실행 시 모듈 유형 경고가 출력되지만 실패하지 않았다.

## 남은 확인

1. 안전한 테스트 계정에서 로그인 성공·세션 만료·로그아웃 후 이력 이동.
2. 회원별 지난 결과 선택, 저니 시작·미션 완료·피드백 저장 실패 및 재시도.
3. 멤버십·체크아웃의 테스트 결제 취소와 복귀.
4. 실제 iOS Safari 및 Android 뒤로가기/제스처, 앱 재시작 시 동작.
5. 인증된 환경의 주소 입력·시트 닫기·타이머 재진입에 대한 UI 회귀 검사.

위 항목은 운영 데이터나 실결제로 대신 검증하지 않았다.
